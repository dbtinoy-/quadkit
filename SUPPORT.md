# Support

## Documentation

The documentation site covers installation, your first application, and a
runnable feature tour:

- **Docs site:** https://oridecon.dev/quadkit/
- **Get started:** [Installation](docs/getting-started/installation.md) →
  [Your First App](docs/getting-started/first-app.md)
- **Feature tour:** [`docs/guides/examples/features/`](docs/guides/examples/features/) —
  runnable showcases, one feature per file, each an executable test

## Questions and problems

- **Bugs and feature requests:** open an issue using the
  [bug report](../../issues/new?template=bug_report.yml) or
  [feature request](../../issues/new?template=feature_request.yml)
  template. Please include the version, Python version, and a minimal
  reproduction.
- **Security vulnerabilities:** do **not** open a public issue — follow
  [SECURITY.md](SECURITY.md) so the report stays private until a fix ships.

## Contributing

Pull requests are welcome — see [CONTRIBUTING.md](CONTRIBUTING.md) for the
development setup, the commit format, and the DCO requirement.

## Status

Quadkit is alpha software (`0.x`): pin your versions and expect public APIs
to evolve before 1.0. Each release's changes are summarized in
[CHANGELOG.md](CHANGELOG.md).
